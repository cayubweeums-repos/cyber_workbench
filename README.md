# cyber_workbench
Simple easy to use workbench for security engineers, threat investigators, and anyone looking to play with malware

# Quick Start
1. Clone the repo
   - `git clone https://github.com/cayubweeums-repos/cyber_workbench.git`
2. cd to the project
   - `cd cyber_workbench`
3. Run the project
   - `make start`
